## Adding a tool

- Copy the `<article class="tool">` block in the website's `index.html` and fill it in.
- Add the Ukrainian strings to `L.uk` with new keys (e.g. `t2`, `t2d`).
- Add one line under "Tools" in `profile/README.md`.
